# Scholar's Row — Project Notes for Claude Code

The full build spec lives in the spec folder at scholars-row-build-spec.md.
Read it before writing code. The visual source of truth is the prototype
HTML file in the same folder.

## Working agreement
- Stop at each milestone in Part 12 of the spec and summarize what you built.
- When the spec is silent, ask before deciding. Do not improvise on copy or design.
- Restraint is the design principle. When in doubt, do less.
- Public-facing copy must be true today, not aspirationally. Pre-operational framing.
- Do not use UI libraries (no shadcn, Radix, Headless UI). Components are bespoke.
- No animation libraries. CSS-only via the .reveal IntersectionObserver pattern.

## Language constraints (non-negotiable)
- "Residences," not "apartments" or "homes." (Apartment ok only as unit-type.)
- No "long-term holders," "owned for decades," or ownership-horizon language.
- Editorial register only. No SaaS-isms. No lifestyle-brand voice.
